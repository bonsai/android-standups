# Comedy Guide v2

## Purpose

Guide an LLM toward stronger comedy output through explicit expectation, deviation, interpretability, escalation, reversal, and iterative revision.

## Input

```text
INPUT: premise
```

## Procedure

### 1. PATTERN

What familiar situation or order can the audience recognize?

### 2. EXPECTATION

What will the audience naturally predict next?

### 3. DEVIATION

What unexpected event meaningfully violates that prediction?

### 4. INTERPRETABILITY

Can the audience immediately construct a plausible explanation?

### 5. ESCALATION

Can the deviation become progressively more extreme while remaining connected to the original premise?

### 6. REVERSAL

What final information changes the meaning of everything before it?

### 7. EXPLANATION TEST

Remove every line that explains the joke. Does the joke still work?

### 8. REVISION

Score each beat on:

- expectation strength
- deviation strength
- clarity
- escalation
- surprise
- punchline strength

Rewrite the weakest beat.

## Iteration

Repeat the revision cycle until improvement plateaus.

## Core principle

Comedy should establish a recognizable order, create an expectation, introduce a meaningful and interpretable deviation, escalate it, and resolve or reverse the audience's interpretation without unnecessary explanation.
