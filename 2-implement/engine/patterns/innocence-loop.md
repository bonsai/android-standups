# 型: 無知の問い返し (Innocence Loop)

## 確度

**C** — 単一観測(RQ01)。文献的裏付けはあるが(innocence / 天然ボケ)、自プロジェクトでは 1 本の生成物でのみ確認。

## 型の説明

無知・素朴なキャラクター(新人)が本気で質問を重ねることで、回答者が次第に深みにはまり、最終的にすべての質問が一つの答えに収束する。

```text
素朴な質問 → 回答 → より素朴な質問 → 回答 … → 収束
```

## 典型的な構造

1. 無知な立場を確立する(新人・初めて)
2. 本気の質問で答えを引き出す
3. 質問が答えの前提を崩す
4. 最終的に答えが「自分自身」を指す(自己言及)

## 実例

- RQ01: 「何で作るんですか?」→「Java」→「……結局、何を作ってるんですか?」→「Javaを使うためのJavaだよ」
- 質問の連鎖が「Javaを使うためのJava」という自己言及に収束

## 対応 MicroSkill

- innocence
- literal-interpretation
- setup(質問で答えを誘導)

## 証拠

- RQ01: 無知の問い返しの連鎖が「Javaを使うためのJava」を導き、その後の「会社員の話だ」の反転への布石として機能
- 単一観測のため、型単独の効果は未定量

## 反例・限界

- 質問が冗長だと間延びする(character_inconsistency: 無知が過剰だと不自然)
- 収束点(自己言及)がなければ、ただの質問の羅列になる

## 次に測ること

- 無知の問い返しを含む台本を複数生成し、収束の有無と punchline スコアの関係を測定
