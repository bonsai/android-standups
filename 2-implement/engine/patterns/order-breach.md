# 型: やぶれ (Order Breach) — マスター型

## 確度

**B** — H-001 の中核メカニズムとして、RQ01 / RQ01b の逸脱データが間接支持。文献(incongruity-resolution 理論)とも整合。ただし「やぶれが境界を可視化する」ことの直接測定は今後の課題。

## 型の説明

笑いは秩序の境(ボーダー)を発見する。そして**境は「やぶれ」によってのみ発見可能**である。

やぶれとは、期待の境界を越える逸脱の出来事。やぶれが起きた瞬間、それまで不可視だった境界が可視化され、笑いがその発見をマークする。

```text
秩序 Order
  ↓
境 Boundary (不可視)
  ↓
やぶれ Breach (逸脱の出来事)
  ↓
発見 Discovery (境界の可視化)
  ↓
笑い Laughter (発見のマーク)
```

## 基本式

```text
笑い = 秩序の境の 発見
発見 = やぶれ の 観察
```

「何が、何から、どの方向へ、どれだけズレたのか」(基本モデルの問い)は、やぶれの測定そのものである。

## やぶれの4性質

| 性質 | 問い | 対応概念 |
|------|------|----------|
| 方向 | 何が・何から・どの方向へ | deviation vector の軸 |
| 距離 | どれだけ越えたか | boundary distance |
| 修復可能性 | やぶれた後、秩序は修復されるか | resolution / reversal |
| 検出可能性 | やぶれが観察・解釈可能か | interpretability |

## 型との関係

コレクション内の全型は「やぶれ」の実装例である。

| 型 | やぶる境界 |
|----|------------|
| 不一致-解決 | 解釈の境界 |
| 開き直り | タテマエ(隠すべき)の境界 |
| 欠陥の目的化 | 価値評価(欠陥/目的)の境界 |
| エスカレーション・ラダー | 度合い(ここまでが普通)の境界 |
| 期待の反転 | 文脈・意味の境界 |
| 具体数字の誇張 | 量(現実的範囲)の境界 |
| 無知の問い返し | 知識(知っているべき)の境界 |
| タテマエとホンネの交換 | 言葉の意味の境界 |
| ボケとツッコミ | 役割の境界 |
| 優越 | 能力・立場の境界 |
| 解放 | 緊張の境界 |

## 証拠

- RQ01b: deviation が integrated +2.0、surprise +2.3 — やぶれの提示が笑いスコアと連動
- RQ01b: baseline は deviation 3.3 と低く、やぶれが弱い台本ほど humor が低い(3.3)
- 文献: incongruity-resolution(境界の越境が笑いの中核)
- H-001「笑いは秩序のボーダーの発見器である」の操作的表現として位置づけ

## 反例・限界

- やぶれが大きすぎる → 境界ではなく「別の秩序」に見える(uninterpretable_deviation)
- やぶれが小さすぎる → 境界に到達しておらず気づかれない(trivial_deviation)
- やぶれの後に修復(解決・反転)がない → 単なる違和感・不快になる(over_escalation / weak_reversal)
- やぶれを説明すると死ぬ(explained_joke)。発見は観客側に委ねる

## 次に測ること

- やぶれの方向が境界の可視化効率に与える影響(どの軸のやぶれが笑いやすいか)
- 修復可能性(やぶれっぱなし vs 修復あり)と笑い率の関係
- やぶれの距離(境界距離)と笑いの最適領域(H-002 との接続)
