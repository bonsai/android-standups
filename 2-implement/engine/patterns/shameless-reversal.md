# 型: 開き直り (Shameless Reversal)

## 確度

**B** — 自プロジェクト実験(RQ01, RQ01b)で支持。ただし単独使用は弱いことも確認済み(下記 反例・限界)。

## 型の説明

失敗・欠陥・矛盾を認めるどころか、堂々と「そうだ」と肯定することで、秩序(普通は隠す・誤魔化すべき)と発話(隠さない)のズレを作る。

```text
欠陥の提示 → 期待(言い訳・修正) → 肯定(逸脱) → 強化
```

## 典型的な構造

1. 欠陥を提示する
2. 観客は言い訳・修正を期待する
3. 欠陥を平然と肯定する
4. (強化) 肯定をさらに推し進める

## 実例

- RQ01: 「この処理、3行で書けました」→「だから設計書が30ページ必要なんだ」(欠陥=非効率を肯定)
- RQ01b baseline-php: 「エスケープの仕方がわからなかったので、入力を受け付けないようにしました」→「でも安全です」

## 対応 MicroSkill

- deadpan(平然と肯定する)
- literal-interpretation(字義通りに受け取る)
- understatement

## 証拠

- RQ01: punchline「だから設計書が30ページ必要なんだ」が反転として機能
- RQ01b baseline-php: 開き直り単独(humor 3/7, deviation 3/7)は flat roast に終わった → **型単独は弱い**という反証的証拠も同時に得ている

## 反例・限界

- 開き直りを 1 回で終わらせると trivial_deviation / weak_escalation になる(baseline-php)
- エスカレーション・ラダーや期待の反転と組み合わせたとき punchline として強く機能する

## 次に測ること

- 「開き直り単独」vs「開き直り+エスカレーション」の対照生成で、組合せ効果を定量化する
