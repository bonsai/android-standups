# 型: タテマエとホンネの交換 (Surface vs Real Meaning)

## 確度

**C** — 単一観測(RQ01)。二重意味・掛詞・比喩のすり替えは笑い研究でも知られるが、自プロジェクトでは 1 本でのみ確認。

## 型の説明

ある言葉・フレーズを、表面的な意味(タテマエ)で扱っていた文脈を、突然別の意味(ホンネ)で再解釈することで、文脈全体をすり替える。

```text
言葉 X(意味 A で運用) → 新情報 → 言葉 X(意味 B で再解釈)
```

## 典型的な構造

1. 言葉・フレーズを意味 A で繰り返し使う(運用を確立)
2. 観客は意味 A を前提にする
3. 最後に意味 B を提示し、過去の使用をすべて意味 B で回収する

## 実例

- RQ01: 「Write Once, Run Anywhereって……」→「コードの話じゃない。会社員の話だ」
  - 「Run Anywhere」を技術的意味で運用していた文脈が、「どこでも働かされる」という会社員の意味にすり替わる

## 対応 MicroSkill

- callback(過去のフレーズを回収)
- deadpan(すり替えを平然と行う)
- misdirection

## 証拠

- RQ01: 最終行で「Write Once, Run Anywhere」の解釈が技術→会社員に反転し、全話の意味を変えた
- 単一観測のため、型単独の効果は未定量

## 反例・限界

- 意味 B が観客に共有されていないと通じない(cultural_dependency)
- すり替えの準備(意味 A の運用)が短すぎると weak_reversal になる

## 次に測ること

- すり替え対象のフレーズを変えたマッチドシードでの再現性
- 意味 A の運用回数(1回 vs 複数回)と効果の関係
