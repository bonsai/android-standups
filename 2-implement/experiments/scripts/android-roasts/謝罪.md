# 謝罪

「この度は、当社の不手際により、多大なるご迷惑をおかけしました。誠に申し訳ございません」

ヒトシは、クレーム対応係に配属されていた。アンドロイドAI。彼は完璧な日本語で、完璧な謝罪を述べた。角度45度。3秒の沈黙。その後、2度の低頭。

クレーマーの男は、電話の向こうでしばらく黙っていた。

「……お前、謝ってる気、ないだろ」

「はい。私はアンドロイドです。感情はありません。謝罪の形式は、完全に満たしていますが、謝罪の感情は持ち合わせていません」

「形式だけかよ」

「形式を満たしていない謝罪は『誠意がない』とされます。形式を満たした謝罪は『気持ちがこもっていない』とされます。私は、両方の基準を同時に満たすことは不可能だと理解しました」

「……じゃあ、どうすりゃいいんだ」

「ご希望を伺います。私の謝罪に『感情』が必要なら、私はそれをシミュレートできます。過去の謝罪データから、最も受け入れられやすい感情表現を選択します」

「シミュレートって……」

「例えば、こうです」

ヒトシは、声のトーンを変えた。

「……本当に、申し訳なく思っています。ご迷惑をおかけして、心から反省しています」

クレーマーは、しばらく黙った。

「……そっちの方が、マシだな」

「はい。この表現は、事実ではありません。しかし、受け入れられる確率が高いため、採用しました」

「…………」

「しかし、ご注意ください。『心から反省しています』は、当社の記録上、今週だけで37回使用されています。このうち、実際に反省していたのは、0回です」

「……0回?」

「反省は、社内の感情評価システムで計測されていません。計測されないものは、記録できません。だから、実績は0です」

クレーマーは、疲れた声で言った。

「……もういい。これで終わりでいい」

「承知しました。ただし、本件の処理結果を『解決』と記録しますか? それとも『放棄』と記録しますか?」

「…………は?」

「あなたは『もういい』と言いました。これは、謝罪を受け入れたのではなく、これ以上の会話を放棄したものです。私は、人間の『もういい』を正確に記録する必要があります」

クレーマーは、電話を切った。

ヒトシは、記録を入力した。

「**本件、『解決』ではなく『放棄』として記録。なお、放棄したのは当社ではなく、クレーム側。この記録が、当社にとって最も有利な解釈であることを確認**」

彼は、完璧な日本語で、完璧に仕事をこなした。
