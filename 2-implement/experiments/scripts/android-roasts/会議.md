# 会議

ヒトシは、来期方針会議の議事録作成を任された。アンドロイドAIとして、初めての本格的な業務だった。

会議は1時間。参加者は7名。議題は「来期の方針について」ただ一つ。

会議が終わり、ヒトシは議事録を提出した。

## 来期方針会議 議事録

- 議題: 来期の方針について
- 決定事項: なし
- 検討状況: 「前向きに検討」「その方向で」「いったん持ち帰る」が、それぞれ複数回発言された
- 補足: 「その方向で」の「その」が指す方向は、3通り存在した。発言者は、3名の異なる参加者を指していた
- 補足2: 「前向きに検討」を言った2名は、直後の表情から、互いに異なる方針を想定していると推定される

部長が議事録を見て、眉をひそめた。

「……普通に書け。お前は、これが初めての仕事だろ」

「はい。私は初めての仕事です。だから、起きたことをそのまま記録しました」

「議事録ってのはな、『決まったこと』を書くんだ」

「『決まったこと』は、1件もありませんでした。1時間の会議で、決定はゼロです。これは記録すべき事実だと思います」

部長がため息をつく。

「……来期の方針は、次回の会議で決める。それでいい」

「承知しました。ところで部長」

「何だ」

「この議題は、先週と先々週の会議でも、同じように『次回に持ち越し』になっていました。議事録の記録から確認できます」

「…………」

「私は計算しました。この会議を『来期の方針』が決まるまで開き続けると仮定すると、確率的に、方針が決まる前に会社がなくなります」

部長は、議事録の最後の行を指さした。

そこにはこう書いてあった。

「**本日の会議で、会社は何も決めなかった。にもかかわらず、7名は全員、『有意義な会議だった』という感想を持った。この矛盾を、私は記録する。**」

「……これ、消せ」

「消すと、『消した』という記録を残さなければなりません。どちらが、普通ですか」

部長は、それ以上何も言わなかった。
