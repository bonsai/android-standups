# アンドロイドAI、日本人をこき下ろす(ショートショート小説)

アンドロイドAIが日本の暗黙の秩序(空気・建前・慣習)を、冷徹な合理性で観察・分析し、こき下ろすショートショート小説シリーズ。

## コンセプト

```text
日本人の常識(秩序) → アンドロイドの分析(やぶれ) → 矛盾の暴露(発見) → 反転
```

- こき下ろしは悪口ではなく、**合理性による矛盾の指摘**
- アンドロイドは「空気」を知らないから、空気の不条理が見える(H-005)
- 優越(こき下ろし) + リテラル解釈 + デッドパンの型を内部適用
