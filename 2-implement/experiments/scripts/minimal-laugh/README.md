# ミニマムに笑いを作る動画

## 設計思想

> **最小の制作で、最小の笑い構造を回す。**

```text
制作: テキスト + 音声合成ナレーション(画像なし・編集最小・完全無料)
笑い: セットアップ(1文) + やぶれ(1文) = 2文で笑いを作る最小単位
```

## ミニマム動画フォーマット

| 要素 | 内容 | コスト |
|------|------|--------|
| 映像 | 単色背景 + テキスト表示(字幕) | 0円 |
| 音声 | 音声合成ナレーション(無料サービス/OS内蔵) | 0円 |
| 長さ | 15-90秒(Short対応) | — |
| 編集 | テキスト表示のみ(ffmpeg/無料アプリ) | 0円 |
| LLM | ネタ生成 | 数円 |

→ **1本あたり実質0円(LLMのみ)**。最速・最量産フォーマット。

## ミニマム笑いの構造(理論)

| レベル | 構造 | 説明 |
|--------|------|------|
| L1 | ワンライナー(1文) | セットアップとやぶれが1文に同居 |
| L2 | 2行(問答・対比) | 期待(1文)→反転(1文) |
| L3 | 3行(定型) | セットアップ→やぶれ→オチ |
| L4 | 90秒小説 | 秩序→期待→やぶれ→反転→余韻 |

**L2が基本単位**: 期待を立てて、1文でやぶる。これが「やぶれの最小単位」。

## 制作パイプライン

```text
ネタ生成(LLM, 数円) → ★自分が見て面白いか(フィルタ) → テキスト化 → 音声合成 → 動画化(無料) → 配信
```

- 1本の制作時間: 数分(ネタがあれば)
- 曜日テーマ・番組表のネタもこのフォーマットで先行配信できる(在庫のスピードテスト)
