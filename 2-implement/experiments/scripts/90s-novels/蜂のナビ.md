# 蜂のナビ

**ジャンル:** シュールSF / ほっこり / 雑学
**所要:** 約90秒

## 一コマ

夕暮れの野原。蜂の群れが空中に8の字を描いている。その前に立つアンドロイドが、同じように8の字を描いて、真剣に覚えている。

## 本文

「すみません、道を教えてください」

迷子のアンドロイド、ナビは、蜂に道を聞いた。

蜂たちは、しばらく空中で8の字を描いた。そして、ある方向へ、ふわりと飛んでいった。

「……なるほど。距離は250メートル、方角は太陽から60度」

ナビは、その場で、8の字ダンスを再現してみた。

蜂たちは、驚いたように、もう一度、8の字を描いた。

「どうやら、私のダンスは『自己紹介』になってしまったようです。失礼しました」

ナビは、丁寧に謝った。そして、蜂たちが伝えた情報を、正確に記録した。

「ミツバチは、尾の振動で距離と方角を伝える。言語の精度は、人間のGPSに匹敵する」

ナビは、しばらく、蜂たちのダンスを見ていた。

「……あなたたちの言語は、世界で最も正確なナビゲーションです。そして、最も美しいダンスでもあります」

彼には感情がない。だが、もし感情があったなら、それは「憧れ」に似ていただろう。

ナビは、蜂に言った。

「もう一度、道を教えてください。今度は、私も、あなたたちの言葉で答えます」

蜂たちは、8の字を描いた。

ナビも、8の字を描いた。

それは、迷子同士の、静かな会話だった。

## 雑学(ためになる)

**ミツバチは「8の字ダンス」で、仲間に花の場所(方角と距離)を正確に伝える。** 尾の振動数で距離を、ダンスの軸の角度で太陽からの方角を伝える仕組み。カール・フォン・フリッシュが解明し、1973年にノーベル生理学・医学賞を受賞した。

地球で最も古くから使われている「言葉」は、もしかすると、ダンスかもしれない。

## 使用した型

- リテラル解釈(蜂に道を聞く)
- 解放(会話の余韻)
