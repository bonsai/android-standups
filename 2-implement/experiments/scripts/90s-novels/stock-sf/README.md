# 株式投資SF(90秒小説シリーズ)

株式投資の雑学 × シュールSF × ほっこり。

## コンセプト

```text
投資の世界(秩序) → アンドロイドの視点(やぶれ) → 投資の雑学(解決) → ほっこり
```

アンドロイド投資AIが、人間の投資行動を「非効率」と分析するが、最後にその「非効率」の中に知恵(複利・長期・単純さ・小さな一歩)を見つける。
