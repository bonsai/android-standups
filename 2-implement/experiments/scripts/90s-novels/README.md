# 一コマ漫画 × 90秒小説(ほっこり × 雑学 × シュールSF)

## 形式の決定(小説に限定)

**90秒ショートショート小説に一本化。** 動画化は字幕+ナレーション(ffmpeg, 無料)で完結する。
一コマは任意(サムネイル用)。4コマ漫画・コントはアーカイブ(他形式は作らない)。

1話 = **90秒で読めるショートショート小説(300-450字) + 雑学BOX**

## 構造(理論マッピング)

| 段 | 機能 | 理論 |
|----|------|------|
| 導入 | シュールSFの設定(アンドロイド・宇宙・深海・未来) | Order(秩序) |
| やぶれ | 常識を裏切る展開 | Deviation |
| 解決 | **実在の雑学**で物語が回収される | Reversal(反転) |
| 余韻 | ほっこり(暖かい気持ち) | 解放(Relief) |

**「ためになる」がパンチライン**: 反転の正体は作り話ではなく現実の事実。驚き+学び+温かさが一度に来る。

## 雑学の条件

- すべて実在の事実(要確認)
- 人間の「想い」に接続できるもの(花言葉・言語・発光の理由など)
- 物語の反転として機能するもの

## 制作パイプライン

```text
1. LLMで90秒小説生成(数円) + 雑学の事実確認
2. 一コマを画像生成(1枚5-30円)
3. 動画化: 静止画1枚 + 字幕 + ナレーション(90秒, ffmpeg, 無料)
4. 配信(Shorts等) → 反応データ(再生・高評価・コメント)
```

## コスト

| 項目 | 単価 |
|------|------|
| 90秒小説(LLM) | 数円 |
| 一コマ画像 | 5-30円 |
| 動画編集 | 無料 |
| **1話あたり** | **10-40円** |

→ 1万円で **300-1,000話** の原案が作れる。コストはほぼ画像のみ。

## ジャンルかけ合わせ(量産フレームワーク)

1話 = **軸A(世界観) × 軸B(トーン) × 軸C(題材/雑学)** の組み合わせ。

| 軸A 世界観 | 軸B トーン | 軸C 題材/雑学 |
|-----------|-----------|--------------|
| シュールSF / タイムトラベル / 深海 / 宇宙 / ホラー / ファンタジー | ほっこり / 風刺 / こき下ろし / 切ない / ユーモア | 株式投資 / 生物 / 宇宙 / 歴史 / 言語 / 科学 / 文化 |

例:
- 株式投資 × こき下ろし × 風刺
- 株式投資 × ほっこり × タイムトラベル
- 生物 × こき下ろし × 風刺
- 宇宙 × 切ない × 雑学
- 株式投資 × ホラー × 風刺

かけ合わせの異なる組合せを量産し、どれが反応を得るかを評価する(データ駆動で軸を絞る)。
