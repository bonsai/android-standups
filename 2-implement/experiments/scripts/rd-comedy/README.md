# 研究開発コントシリーズ(R&D Comedy)

研究開発そのものを題材にしたコントシリーズ。材料はすべてこのプロジェクトの実体験。

## コンセプト

```text
研究(真面目) → コント(笑い) → 反応データ(実証)
```

- 研究開発の日常(科研費・実験・評価・理論説明)をそのまま舞台にする
- 理論は内部適用: 各コントに型・やぶれ・分布の山を組み込む
- 実演(Step 0 台本プール)の第一弾。観客の反応 = laughter データ

## 作品一覧

| 作品 | 題材 | 主な型 |
|------|------|--------|
| [科研費、47歳](科研費、47歳.md) | 年齢制限・無所属での資金申請 | エスカレーション・ラダー / 期待の反転 |
| [つまらない台本を保存する](つまらない台本を保存する.md) | 「失敗はデータ」の原則 | 欠陥の目的化 / 開き直り |
| [AI評価と人間評価](AI評価と人間評価.md) | 評価者間不一致(AI_human_disagreement) | 期待の反転 / ボケとツッコミ |
| [やぶれの説明](やぶれの説明.md) | 理論の真面目な説明 | タテマエとホンネの交換 / 解放 |

## 理論の内部適用

- 各コントは「秩序 → 期待 → やぶれ → 発見 → 笑い」の構造を持つ
- パンチラインは説明せず、観客に解決を委ねる(explained_joke 禁止)
- 実演時の反応で、どの型・どのズレ距離が効くかを検証する

## 進め方

```text
コント執筆 → 実演(音声/映像) → 反応記録 → 型・ズレ距離の調整 → 次作
```
