# やぶれの説明

**風刺対象:** 研究者の理論マウント(すべてを理論で回収する)
**構造:** 1=理論の当然 / 2=期待 / 3=不条理の暴露 / 4=風刺の刃

## 1コマ

飲み会。研究員が熱く語る。

研究員: 「笑いとは、秩序の境の発見です。境は『やぶれ』によってのみ可視化されます」

同僚: 「へえ」

## 2コマ

研究員: 「今の『へえ』も、会話の期待をやぶる微小な逸脱ですね」

同僚: 「…………」

研究員: 「沈黙は、解釈不能な逸脱です。uninterpretable_deviation」

## 3コマ

同僚: (思わず笑う)

研究員: 「笑いましたね。なぜ笑ったか、説明します——」

同僚: 「説明するな!!」

## 4コマ

研究員: 「今のツッコミも、ボケとツッコミの役割交換です」

同僚: 「うるさい!!」

研究員: 「『うるさい』は、会話の境界をやぶる——」

同僚: 「**お前という秩序をやぶりたい**」

研究員: 「それも笑いの型です。記録します」

同僚: 「帰れ!!」
