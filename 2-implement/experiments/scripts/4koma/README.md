# 4コマ漫画 → 動画 制作(実作の主形式)

## 形式の決定

コント(長尺)から **4コマ漫画 → 動画化** に絞る。

理由:
- 4コマの構造が理論と1対1で対応する(下記)
- 制作コストが極小(LLM数円 + 画像/字幕/ナレーション)
- 動画(Short/配信)と相性が良く、反応データが取りやすい

## ジャンル: 風刺

**4コマ = 風刺の最小単位** として作る。笑わせつつ、制度・慣行・言説の不条理を刺す。

| コマ | 風刺の機能 | 理論 |
|------|-----------|------|
| 1コマ | 風刺対象の「当然」を提示(制度・慣行・言説) | Order |
| 2コマ | それが正しいものとして進行 | Expectation |
| 3コマ | 不条理・矛盾の暴露 | Deviation(やぶれ) |
| 4コマ | 風刺の刃(対象を刺す反転) | Discovery / Reversal |

風刺対象: 科研費制度 / 論文文化 / AI評価ブーム / 研究者の理論マウント / 資金申請 など。
笑わせて終わるのではなく、**見る側が「ああ、確かに」と思う刃**を4コマ目に置く。

## 4コマ = やぶれの最小単位(理論マッピング)

| コマ | 機能 | 理論 | 型 |
|------|------|------|-----|
| 1コマ | 秩序の確立 | Order(普通の場面) | setup |
| 2コマ | 期待の確立 | Expectation(このまま行くはず) | setup / misdirection |
| 3コマ | やぶれ | Deviation(期待を裏切る) | exaggeration / literal / innocence |
| 4コマ | 発見・反転 | Discovery / Reversal(意味が変わる) | punchline / callback / defect-as-purpose |

**4コマ漫画 = やぶれによって秩序の境を可視化する最小装置。**

## 制作パイプライン

```text
1. シード → LLMで4コマ台本生成(1本 数円)
2. 選別: 評価者LLMで分布の山のピーク(d=3-4)付近を優先 + 評価者分離
3. 絵: 画像生成(1枚5-30円) or 手書き/フリー素材(無料)
4. 動画化: 静止画4枚 + 字幕 + ナレーション(ffmpeg等, 無料)
5. 配信: YouTube Shorts / ニコニコ
6. 反応: 再生・高評価・コメント・笑い = laughter proxy データ
```

## コスト(1万円予算)

| 項目 | 単価 | 100本 |
|------|------|-------|
| LLM 4コマ生成 | 数円/本 | 数百円 |
| 画像生成(安価モデル) | 5-30円/枚 × 4 | 2,000-12,000円 |
| 動画編集・配信 | 無料 | 0円 |
| **合計** | | **数千円〜1.2万円** |

→ 1万円で **80-100本の4コマ動画** が作れる。コストはほぼ画像生成のみ。

## 反応データの扱い

- 再生数・高評価・コメント = 笑いの proxy(Phase 1 の laughter 相当)
- コメントの感情分析で「どの型が効いたか」を検証
- 分布の山のピーク(どのズレ距離のネタが反応を得るか)を配信データで実測

## 材料

研究開発ネタ([rd-comedy](../rd-comedy/README.md) の題材を4コマ化):
科研費 / 失敗の保全 / AI評価と人間評価 / やぶれの説明 / 資金申請 / エージェント作業
