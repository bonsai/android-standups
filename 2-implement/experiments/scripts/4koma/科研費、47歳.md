# 科研費、47歳

**風刺対象:** 科研費制度(年齢制限・所属要件)
**構造:** 1=制度の当然 / 2=形式的な進行 / 3=不条理の暴露 / 4=風刺の刃

## 1コマ

研究支援課。窓口のお姉さんと、47歳の「研究志望者」。

窓口: 「科研費のご相談ですね。若手研究は39歳以下です。おいくつですか?」

志望者: 「47です」

## 2コマ

志望者: 「心は若手ですが」

窓口: 「心は審査対象外です」

志望者: 「では、基盤研究Cで。所属機関は……自宅です」

## 3コマ

窓口、書類をめくる。

窓口: 「自宅は『研究機関』に該当しませんね。……『自宅兼ネタ工房』と書いておきました。これで応募はできます」

志望者: 「えっ、応募できるんですか!?」

## 4コマ

窓口、優しく微笑む。

窓口: 「**応募はできます。落ちますけどね**」

志望者: 「…………」

窓口: 「47歳の心は、書類のどこにも書けないんですよ」
