# 論文という名の彫刻

**風刺対象:** 論文文化(中身より形式・「今後の課題」の濫用)
**構造:** 1=慣行の当然 / 2=進行 / 3=不条理の暴露 / 4=風刺の刃

## 1コマ

研究室。教授が院生に指導する。

教授: 「結果が出なくても論文は書けます。『失敗の分析』というタイトルでいきましょう」

院生: 「でも、データが全然……」

## 2コマ

教授: 「『データ不足の考察』にすればいい」

院生: 「それ、中身が空っぽです」

教授: 「『今後の課題』を10ページ書けば、論文になります」

## 3コマ

院生: 「これで博士号をもらえるんですか?」

教授: 「博士号は、論文を書いた人にではなく、『今後の課題』を残した人に授与されます」

## 4コマ

院生: 「……つまり、この研究室の博士号は全部、未来の人がもらうんですね」

教授: 「**私もまだもらってません。だから今後の課題を書き続けているんです**」
