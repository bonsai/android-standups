## 戦略(優先順位)

```text
Phase 1(0-6ヶ月): 実演台本プール → 動画公開 → 観客反応データ
                  → 文化庁メディア芸術祭 + アーツカウンシル東京 応募
Phase 2(6-12ヶ月): 受賞・選出実績 → ポーラ財団/電通普 助成応募
                  → クラファン(実機・実演) → 月額支援開始
Phase 3(12-24ヶ月): 実機導入 → 実演イベント → メディア芸術祭出品
                  → 企業共同(ロボット/LLM/エンタメ)打診
```

## 優先 3 件(最初に取り組む)

1. **文化庁メディア芸術祭** — 応募(作品)だけで実績になる。アンドロイド漫才の本丸
2. **アーツカウンシル東京** — 個人応募可・金額も大きい・公演実績がなくても企画力で勝負
3. **クラウドファンディング** — 実演・実機をすぐ資金化。観客=支援者=データ源
