# 番組表(TV局モデル)

## コンセプト

チャンネルを**1つの放送局**と見立て、番組表(TV欄)で運営する。各番組は90秒セグメントのシリーズ。**すべての番組を設計し、配信は週次スケジュールに従って順次放送**する。

```text
番組表(全番組を設計) → 番組 = 90秒セグメントのシリーズ → 週次で放送
```

## 90秒の番組フォーマット(全番組共通)

```text
OP(5秒): 番組ジングル・ロゴ → 視聴者が「この番組だ」と判別
本編(60秒): 小説/スタンド/4コマ
雑学BOX(15秒): 「ためになる」一行
ED(10秒): 次回予告・プレイリスト誘導
```

## 曜日テーマとの連動

- 夜の番組(21:00)は曜日の漢字テーマに直結: 月=月, 火=火, 水=水, 木=木, 金=金, 土=土
- おひるの雑学は「その日のテーマ」を先取りする昼の一話
- 日曜は「日の日曜」: 太陽・光の小説は「太陽の目覚まし」と「独演(太陽ネタ)」に分散

## 番組表の効用

1. **ブランド**: 番組名がチャンネルの顔(「夜の水」と言えば深海の話)
2. **習慣**: 放送枠固定で視聴者が「21時=夜の番組」と習慣化
3. **在庫管理**: 番組ごとに在庫を数えられる(各番組のエピソード番号)
4. **データ**: 番組別に metrics を集計(analytics の単位=番組)
