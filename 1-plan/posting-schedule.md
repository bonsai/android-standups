# 投稿スケジュール(週次)

## 基本方針

- 配分: **90秒小説 6 / スタンドコメディ 3 / 4コマ 1**(60/30/10)
- 本数: 10本/週(1日1-2本の無理のない負荷)
- 時間帯: 固定2枠(**12:00 昼休み / 21:00 夜のメイン**)で視聴習慣を作る
- バッファ: 金曜は1本のみ(4コマ)+ analytics レビュー日

## 曜日テーマ(漢字の字義で固定)

曜日の漢字(日月火水木金土)の**字義そのものをテーマ**にする。視聴者が「今日は何の日」と覚えられる+字義由来の雑学が自動作れる。

| 曜日 | 漢字 | テーマ | 雑学ジャンル | タグライン |
|------|------|--------|--------------|-----------|
| 月 | 月 | **月の月曜** | 月・月光・宇宙 | 「月曜は月の話」 |
| 火 | 火 | **火の火曜** | 火山・炎・エネルギー | 「火曜は火の話」 |
| 水 | 水 | **水の水曜** | 海・深海・水 | 「水曜は水の話」 |
| 木 | 木 | **木の木曜** | 森・林業・樹木 | 「木曜は木の話」 |
| 金 | 金 | **金の金曜** | お金・投資・金属 | 「金曜は金の話」 |
| 土 | 土 | **土の土曜** | 農業・大地・土壌 | 「土曜は土の話」 |
| 日 | 日 | **日の日曜** | 太陽・光 | 「日曜は太陽の話」 |

**由来の雑学(システム自体がコンテンツ)**: 曜日はバビロニアの七曜(惑星)に由来し、日本では五行(木火土金水)+日月と対応。この由来話は「ためになる雑学」として毎月1回配信できる。

## 制作パイプライン(前倒し制作)

```text
週末(土・日): 翌週分10本を一括制作
  - 小説6: LLM生成 → 雑学の事実確認 → 字幕/ナレーション動画化
  - スタンド3: 独演ネタ → 音声合成 or 実演収録
  - 4コマ1: 4コマ生成 → 画像4枚 → 動画化
月〜金: 配信のみ(制作は週末に集中)
```

## Analytics レビューループ(週次)

```text
毎週金曜 21:00 (4コマ投稿後):
  1. 前週の10本の metrics を集計(再生/完視聴/高評価/コメント/保存)
  2. 反応率 = (高評価+コメント+保存)/再生
  3. 形式別・シリーズ別・時間帯別の反応率を確認
  4. 記録: registry.md の Metrics 表に記入
  5. 調整判断: 30本(3週分)溜まるまでは 60/30/10 を維持
  6. 山が出たら次週の配分・時間帯を調整(production-mix.md の再配分ルール)
```

## バッファ・休止ルール

- 金曜は1本のみ(4コマ)+ レビュー → 制作遅れのバッファ
- 3本以上遅れたら、まず小説を減らす(小説は量産で追いつきやすい)
- 連続投稿で固定時間帯を守る(時間帯のブレは視聴習慣を壊す)

## 開始時の在庫

- 90s小説: 16本(90s-001〜016) — 配信済み前提の在庫は 16本分
- スタンド: 1本(アンドロイドの独演) — 続編3本を初週までに制作
- 4コマ: 4本(科研費・論文・AI評価器・やぶれ) — 4週分の在庫あり
