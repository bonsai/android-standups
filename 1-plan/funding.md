# 研究資金とコスト見積もり

## 1. コスト構造(全体像)

この研究のコストは「LLM API(極小)→ 人間 laughter データ(中)→ アンドロイド実機(大)」という構造。計算資源より**人間データと実機**がボトルネック。

| 項目 | Phase | 概算(円) | 備考 |
|------|-------|----------|------|
| LLM API(生成・評価) | 1-4 | 1-5万/年 | 実測ベースで極小(下記§2) |
| 人間 laughter データ | 1-2 | 25-60万 | 謝金・クラウドソーシング |
| カメラ・MediaPipe・GPU | 2 | 5-15万 | MediaPipe 本体は無料 |
| アンドロイド実機 | 3 | 30-200万 | スコープ依存(§2 Phase3) |
| 計測・スタジオ | 3 | 20-50万 | モーション・映像 |
| GPU 学習(自律進化) | 4 | 30-100万/年 | エンジン進化フェーズ |
| 論文発表 | 1-4 | 10-100万/本 | 国内/国際で差 |

## 2. フェーズ別詳細

### Phase 1(現在〜6ヶ月)— 台本・人間評価

**LLM API(実測):**
- RQ01b n=10 相当: 60台本 × ~1.5K出力トークン ≈ 90Kトークン ≈ $1.5
- RQ01c 材料拡張(3回ラン): ≈ 150Kトークン ≈ $2.5
- 評価(生成LLM分離・critique含む ×2): ≈ $5-10
- 年間の徹底実験(プロンプト消去・評価器比較含む): **1-5万円/年**

**人間 laughter データ(主要コスト):**
- クラウドソーシング(笑いの判定 1回50-100円 × 数百件): 5-10万円
- 対面セッション(映像で laughter 検出, 2,000-3,000円/人 × 20人): 4-6万円
- 分析・アノテーション補助: 5-10万円
- 小計: **15-25万円**

### Phase 2(6-12ヶ月)— 非言語観測(MediaPipe)

- Webカメラ・三脚: 1-3万円
- クラウドGPU(リアルタイム処理, 必要時のみ): 3-10万円
- 被験者セッション拡大(マルチモーダル同期): 10-20万円
- 小計: **15-35万円**

### Phase 3(12-24ヶ月)— アンドロイド×漫才(独自性の中核)

| 選択肢 | 概算 | 備考 |
|--------|------|------|
| 小型ロボ(CommU系・タブレット顔) | 10-50万 | 首・表情あり |
| 中型対話ロボ(Tapia / PALRO / Pepper) | 30-80万 | 既成品・SDK |
| 研究用アンドロイド(Alter系・カスタム) | 100-300万 | 研究機関向け |

- 計測(モーションキャプチャ・マイクアレイ): 20-50万
- 小計: **30-200万円**(構成次第)

### Phase 4(24ヶ月〜)— 自律進化

- エンジン進化(評価器フィードバック・軽量チューニング)の GPU: 30-100万/年
- 評価パイプライン運用: 10-20万/年

## 6. 資金用途の優先順位

1. **人間 laughter データ** — この研究の真のボトルネック(sparse oversight でも量的基盤は必要)
2. **アンドロイド実機** — Phase3 の独自性(人間×アンドロイド漫才)
3. **発表・旅費** — フィードバック獲得と実績
4. **計算資源** — 現状では最下位(LLM API が安いため)

## 7. 備考

- **LLM API は年間数万円** — 資金の障壁は計算ではなく「人間データの規模」と「実機」。
- **倫理**: 人間 laughter データ収集は IRB・倫理審査が必要(研究費の一部に計上すべき)。
- **オープンサイエンス強み**: 材料・データ・仮説世代は GitHub 公開済み。資金申請で透明性としてアピール可能。
- **既存アセット**: 型コレクション(確度付き)、RQ01 系列、H-001r/分布の山の仮説 — 申請書の「これまでの成果」欄にそのまま使える。
