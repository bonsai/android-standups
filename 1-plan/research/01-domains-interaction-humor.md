# 01 — Domains-Interaction Approach

## Citation
Hillson & Martin (1994), *What's so funny about that?: The domains-interaction approach as a model of incongruity and resolution in humor*.

## URL
https://experts.mcmaster.ca/scholarly-works/1791686

## Research role
笑いにおける「ズレ」を意味領域間の距離として扱う先行研究。

## Core idea
ジョークでは異なる意味領域が相互作用し、incongruity（不一致）が生じる。incongruityだけでなくresolution（解決）との組み合わせがhumor評価と関係する。

## Method / evidence
250個のジョークを対象に意味領域間の距離とユーモア評価を分析した研究として参照する。

## Relevance
本プロジェクトの「ズレを数値化する」という発想の直接的な先行研究。

## Limitation / gap for this project
単純にsemantic distanceを測るだけでは、本プロジェクトの目標である「何が、何を前提として、どの方向に、どれだけズレたか」という世界知識・Ontologyベースの説明にはならない。

## Project extension
```text
World Knowledge → Order → Premise → Expectation → Deviation Vector → Humor
```

**Research gap:** semantic distanceをLLMが説明可能な構造化されたDeviation Vectorへ拡張する。
