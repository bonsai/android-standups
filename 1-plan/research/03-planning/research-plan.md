# Research Plan

## Trigger
A human hypothesis is the only required initial input.

## Stage 1 — Theme / Hypothesis

Inputs:
- human hypothesis
- domain context

Activities:
- define the research theme
- collect prior research
- build concept ontology
- identify candidate research gaps
- state falsifiable hypotheses

Output:
- hypothesis
- prior-research map
- research-gap candidate

## Stage 2 — Seminar

Activities:
- student presentation
- prior-research challenge
- theory critique
- NLP critique
- cognitive critique
- statistics critique
- domain/comedy critique
- experimental critique
- professor review

Output:
- objections
- decisions
- unresolved questions
- revised hypothesis
- planning requirements

## Stage 3 — Planning

Activities:
- formulate research questions
- operationalize concepts
- define variables
- define datasets
- define annotation protocol
- define baselines
- define evaluation metrics
- define human review points
- define reproducibility requirements

Output:
- research proposal
- experiment specification
- evaluation specification
- execution checklist

## Planning gate

The lab must not move from seminar to experiment without a planning artifact that states:

```text
Research Question
Hypothesis
Variables
Dataset
Method
Baseline
Evaluation
Falsification Condition
Human Review Point
Expected Evidence
```

## Loop

```text
Hypothesis
 → Prior Research
 → Seminar
 → Planning
 → Experiment
 → Evaluation
 → Human Review
 → Hypothesis Revision
 → Hypothesis V2
```

## Current research question candidate

Does an explicit representation of world knowledge, premise, expectation, expected/actual state, and deviation explain human humor judgments better than simpler semantic-distance or LLM-judge baselines?

## Current experiment direction

Manipulate deviation while controlling wording, length, topic, and context where possible. Compare human humor judgments against structured deviation features and baseline evaluators.

## Human role

Humans do not need to supervise every cycle. They review major hypothesis changes, planning gates, unexpected findings, and publication decisions.
