# 02 — Incongruity-Resolution Cases in Jokes

## Citation
Yus (2017), *Incongruity-resolution cases in jokes*.

## URL
https://doi.org/10.1016/j.lingua.2017.02.002

## Research role
「ズレがどこで発生し、どう解決されるか」を分類する研究。

## Core idea
ジョークをincongruityとresolutionの関係として分析し、複数のケースを分類する。500個のジョークを対象とした分析として、本プロジェクトのOntology設計に参考になる。

## Relevance
本プロジェクトの、

```text
Order → Premise → Expectation → Deviation → Resolution
```

という分析系列に対応する。

## Limitation / gap for this project
既存分類をそのままLLM用ルールにするのではなく、世界知識・役割・社会規範・文脈などを機械可読なOntologyとして持つ必要がある。

## Project extension
Deviationを、semantic / role / social / logical / contextual / emotional / linguisticなどの軸に分解し、LLMが説明可能な評価形式にする。
