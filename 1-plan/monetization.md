# 収益化戦略(4ストリーム)

## 全体像

```text
YouTube(無料・認知・データ)
   ↓
note(有料・深掘り・先行収益)
   ↓
コンサル(専門性の現金化・実績ありき)
   ↓
プロダクトPoC(スケール・デモ・再現性)
```

**原理**: 下流(コンサル・PoC)は上流(コンテンツ実績)が営業材料。まず YouTube でデータ、note で先行収益を作る。

## 1. YouTube 収益化

| 項目 | 内容 |
|------|------|
| 前提 | 登録1000人 + (長尺4000時間 or Shorts 1000万再生/90日) |
| 収益 | 広告 / メンバーシップ / スーパーチャット |
| 戦略 | 90秒小説で Shorts の母数 → 長尺(5-10分「雑学まとめ」「理論解説」「朗読」)を併用して視聴時間を稼ぐ |
| 現実 | **収益化まで数ヶ月〜1年**。単価は低い(特に Shorts)。補助収益と位置づけ |
| 注意 | Shorts の 1000万再生ハードルは高い → 長尺併用が実質ルート |

## 2. note 収益化(先行収益)

| 項目 | 内容 |
|------|------|
| 前提 | 登録者数不要。記事単価で即成立 |
| 商品 | 有料記事(100-500円) / 定期購読マガジン(月500-1000円) / スキ(無料) |
| コンテンツ | ① 雑学BOXの解説記事 ② 90秒小説全文+制作メモ ③ 理論の裏話(やぶれ・分布の山) ④ エージェント共同制作のプロセス(obento) |
| 導線 | YouTube(無料) → note(深掘り) 。動画説明文に note リンク |
| 目標 | 月500-1000円×100人 = 5-10万円/月(マガジン確立時) |

**note は最短の収益化ルート**。コンテンツの在庫(16本+型コレクション+理論)がそのまま商品化できる。

## 3. コンサル営業(実績ありき)

| 項目 | 内容 |
|------|------|
| 提供 | ① AI×コンテンツ戦略(生成AIパイプライン構築) ② エージェント構築(obento/ovento 方式) ③ プロンプト設計 ④ 笑い・共感コンテンツの分析(型・分布の山) |
| ターゲット | エンタメ企業 / 広告代理店 / 地方企業の広報 / AI導入企業 |
| 営業材料 | YouTube/note の実績 + 16本の制作パイプライン + obento スキル |
| 単価 | プロジェクト 10-50万 / 月額顧問 5-30万 |
| 開始条件 | **コンテンツ実績が揃ってから**(登録者・記事購読が名刺) |

## 4. プロダクトPoC開発(デモ・スケール)

| 項目 | 内容 |
|------|------|
| PoC候補 | ① 90秒小説生成エンジン(シード→小説+雑学BOX→動画原案) ② 4コマ風刺生成器 ③ 台本選別AI(分布の山で評価) |
| 作り方 | 既存パイプライン(16本生成)を一般化して CLI/Web の最小デモに。**作り込みすぎない** |
| 展開 | コンサル先へのデモ → 実績 → (必要なら)有料化 |
| 役割 | コンサルの提案材料 + 独自技術の見える化 |

## 優先順位とロードマップ

```text
0-3ヶ月:   YouTube 開始(データ収集) + note 開始(即収益化・マガジン構築)
3-6ヶ月:   YouTube 登録1000人 + 長尺併用で視聴時間。note マガジン確立(5-10万/月)
6-12ヶ月:  YouTube 収益化 + コンサル営業開始(実績を名刺に)
12ヶ月〜:  プロダクトPoC(コンサル先デモ)→ スケール判断
```

## 収益の現実的な見込み(12ヶ月後)

| ストリーム | 月収(目安) | 確度 |
|-----------|-----------|------|
| YouTube | 0-5万 | 低(条件が厳しい) |
| note | 3-10万 | 中(記事の質次第) |
| コンサル | 10-50万 | 中(営業力次第) |
| プロダクトPoC | 0-30万 | 低(実績次第) |

→ 現実的な主柱は **note(先行) + コンサル(中核)**。YouTube はデータ・認知の基盤、PoC は将来。

## リスクと対策

| リスク | 対策 |
|--------|------|
| YouTube 収益化に時間がかかる | note で先行収益。YouTube はデータ・認知と割り切る |
| コンサルは実績がないと売れない | 実績(登録者・購読者)を揃えてから営業開始 |
| プロダクト作り込みすぎ | 最小デモ(1画面/1コマンド)で止める。コンサル先デモ専用 |
| 労力の分散 | 全ストリーム同時にやらない。0-3ヶ月は YouTube+note のみ |

## 既存アセットの商品化マップ

| アセット | 商品 |
|----------|------|
| 90秒小説16本+雑学BOX | note 有料記事・YouTube |
| 型コレクション(確度付き) | note マガジン「笑いの型」・コンサル資料 |
| やぶれ/分布の山の理論 | note 解説・コンサル枠(理論武装) |
| obento スキル | コンサル(エージェント構築)・PoC |
| 制作パイプライン(LLM) | プロダクトPoC の土台 |
