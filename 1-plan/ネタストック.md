# ネタソース(Wikipedia)と面白さの基準

## 制作の第一フィルタ

> **「自分が見て面白いか」** を最優先の判定基準にする。

analytics は後で効くが、最初のフィルタは自分の面白さ。自分が面白いと思わないものは、誰の面白さにもならない。

```text
ネタ(Wikipedia) → 小説化 → ★自分が見て面白いか(人間フィルタ) → 動画化 → analytics
                              └ 面白くない → 捨てる(失敗記録)
```

## ネタ源: Wikipedia(日本語版)

- 探し方: 曜日テーマのキーワード + 「雑学」「豆知識」「由来」で探索
- 判定: 自分が「へえ」と思ったものだけストックに残す
- 出典を必ず残す(「Wikipedia: ○○」)— note の出典明記・信頼性にも使える

## ストックの運用

- 各ネタを1枚のカード(上記表)として管理し、小説化したら `済` を付ける
- 面白いと感じたネタは「自分がなぜ面白いと思ったか」を一行残す(ネタの質の学習データ)
- 曜日テーマの在庫が尽きたら、このストックから補充する
- 新ネタは Wikipedia 探索のたびに追加(このファイルを育てる)
