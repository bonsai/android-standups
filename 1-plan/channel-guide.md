# チャンネル運営ジャンル分け指南

1チャンネルで複数ジャンルを扱うための運営マニュアル。ジャンル分け=「予測」ではなく「データで再編する仕組み」と位置づける。

## 1. ジャンル構成(チャンネル内の系列)

> **需要の見立て(2026-08)**: SF 単体の需要は弱い。需要の主役は「雑学」「ほっこり」。**SF は文脈装置**(驚きの舞台)として内部に持ち、表看板には出さない。タイトル・系列名は「雑学・ほっこり・ショートストーリー」で売る。

| 系列 | プレイリスト名案 | サムネ統一(色/書体) | 頻度 | 狙い |
|------|------------------|---------------------|------|------|
| 90秒雑学ストーリー(ほっこり) | 「90秒雑学ストーリー」 | 青系/明朝 | 週4-5 | 母数・保存・共有 |
| 投資雑学ストーリー | 「投資雑学 90秒ストーリー」 | 金系/ゴシック | 週2 | 検索流入・投資関心層 |
| アンドロイド独演 | 「アンドロイド独演(スタンド)」 | 赤系/太字 | 週3 | ブランド・独自性 |
| 風刺4コマ | 「風刺4コマ」 | 緑系 | 週1 | バリエーション |

※ 「SF」はジャンル名・タイトルには出さない(需要が弱い)。内部の文脈装置としてのみ使う。

サムネの色・書体を系列固定する。視聴者が「この色はほっこり系」と瞬時に判別できるようにする(視聴習慣の形成)。

## 2. タイトル・説明文の作法

**タイトルパターン**: `[系列名]｜惹句【雑学】`

```text
例: 90秒小説｜宇宙で最初に咲いた花【サリュート7号】
例: 株式投資SF｜複利の怪物【1円が30日で10億円】
例: アンドロイド独演｜「大丈夫です」は呪文
例: 風刺4コマ｜科研費、47歳
```

- 惹句に「数字」「疑問」「意外」を入れる(クリック率)
- 系列名を先頭に付ける(シリーズ判別+検索)
- 説明文: 雑学BOX(ためになる)+ 関連シリーズリンク + 投資系は注意書き

## 3. 1チャンネルでのジャンル分離(アルゴリズム対策)

チャンネル分割はデータ後(channel-strategy.md)。それまでは以下で分離する:

```text
プレイリスト: 系列ごとに作成(動画を系列で整理)
シリーズ名: タイトル・動画内で統一
タグ: 系列キーワードを固定
```

**流入源をジャンル別にモニタ**(YouTube Studio のトラフィック元):

| 流入源 | 意味 | ジャンル別に何を見るか |
|--------|------|------------------------|
| ショートフィード | 層・趣味 | どの系列がフィードで伸びるか |
| 検索 | 意図 | 投資系は「株 雑学」等の検索が効くか |
| 関連動画 | 系列内連続視聴 | 同じ系列を見てもらえているか(プレイリストの効き) |

**混在ペナルティ監視**: ある系列の動画が他系列の完視聴を下げている(シリーズ間で視聴者が食い違う)サインが出たら、その系列は分割候補。

## 4. ジャンル別の運用ルール

| 系列 | 主な KPI | 運用のコツ |
|------|----------|------------|
| ほっこりSF | 保存・共有率 | タイトルに「ほっこり」「雑学」、エンディングに「続きはプレイリスト」 |
| 株式投資SF | 検索流入・登録 | キーワード(株/投資/複利/NISA)を説明文に。注意書き明記 |
| アンドロイド独演 | 登録・コメント | シリーズ継続(続編「第◯話」)。キャラ(ヒトシ)を固定 |
| 風刺4コマ | シェア | 共感する風刺対象を選ぶ。政治・宗教は避ける(収益化リスク) |

## 5. データによるジャンル再編(週次)

```text
毎週金曜(レビュー日):
  1. 系列別に metrics 集計(再生/完視聴/反応率)
  2. 系列ランキングを作る
  3. 上位系列: 頻度を維持・増やす
  4. 下位系列: 失敗記録(failure)し、統合・停止・作り直しを判断
  5. 30本(3週)溜まるまでは配分60/30/10を維持
```

再編の判断例:

| 状況 | 判断 |
|------|------|
| ほっこりが山 | ほっこりを70%へ、投資を週1へ |
| 投資系が検索で伸びる | 投資を週3へ(検索は安定流入) |
| スタンドが低反応でもコメント多い | 維持(ブランド)。実演版の可能性を検討 |
| 2系列が別々の山 | 分割検討(channel-strategy.md) |

## 6. タグ・キーワード設計(実例)

```text
固定タグ: 90秒小説 / ショートショート / 雑学 / SF / ほっこり
系列タグ: 株式投資 / アンドロイド / スタンドコメディ / 風刺 / 4コマ / 日本文化
検索用: 株 雑学 / 投資 ショートストーリー / 宇宙 雑学 / 深海 雑学
```

- 系列タグは動画ごとに固定(一貫性)
- 説明文の先頭2行にキーワードを自然に置く(検索対策)
- 投資系: 「本動画は投資の推奨ではありません」の注意書きを必ず入れる

## 7. ジャンル分けの失敗パターン

- 系列名・色・タグが動画ごとにブレる → 視聴者が判別できず習慣が壊れる
- 投資系に注意書きがない → 収益化・コンプライアンスリスク
- 風刺の対象が特定の実在団体・人物 → 炎上・収益化リスク(創作上の風刺に留める)
- 系列を増やしすぎる → データが薄まる(ジャンルは最大4つまで)
