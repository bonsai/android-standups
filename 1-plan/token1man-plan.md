# 1万円トークン研究案(オンラインLLMシミュレーションのみ)とアプライ先

## 0. 前提

- 予算: **LLM API 1万円**($65-70)
- 対象外: 人間データ・実機・MediaPipe・GPU(すべてフェーズ外)
- 目的: トークンだけで**申請と発表に使えるデータ**を作り、資金アプライ先を絞って応募する

## 1. 予算配分($67)

| # | 項目 | 内容 | 見積 |
|---|------|------|------|
| 1 | RQ01c 拡張 | 6 level × 2 材料 × 5 item = 60項目、各3変異生成(180) + **評価者分離** | $8-12 |
| 2 | RQ01b 拡張 | 3 seeds × 2 条件 × n=15 = 90台本 + 評価者分離 | $8-12 |
| 3 | 意味距離の客観化 | ローカル埋め込み(無料)で d 軸を cosine 化、humor と相関 | $0-3 |
| 4 | 安定性・アブレーション | guide v2 vs v1 vs なし、同一シード 3 ラン | $5-8 |
| 5 | 予備(リトライ・検証) | 失敗出力の再生成・検証 | $5 |
| | **合計** | | **$27-40 ≈ 4,000-6,000円**(1万円内) |

## 2. 実行スケジュール(2-3ヶ月)

```text
Month 1: RQ01c 拡張(材料生成 → 分離評価) + 予備分析
Month 2: RQ01b n=15(生成 → 分離評価) + embedding で d 軸客観化
Month 3: アブレーション → データ統合 → 国内会議投稿準備 + 申請書データ化
```

## 3. 成果物

1. **分布の山(H-002o)の強化データ**: 6 level × 2 材料 × 5 item × 3 変異、評価者分離、n≥15/level 相当
2. **RQ01b 対照 n=15**: baseline vs integrated、評価者分離
3. **d 軸の客観化**: 埋め込み距離と humor の相関(主観ラベルの代替)
4. **アブレーション**: Guide v2 の手順別寄与(どの手順が効くか)
5. **国内会議投稿原稿**(言語処理学会 or HAI シンポジウム)
6. **資金申請書の実データ**(下記アプライ先)

## 4. このプランの強み

- LLM API は年間数万円で済む(前回見積もり実測) → **1万円で主要実験のデータが揃う**
- 評価者分離(生成と評価を別モデル/別ラン)でバイアス軽減
- 公開リポジトリ(GitHub)に材料・データ・仮説世代がある = 申請・査読で透明性
- 人間データは「資金獲得後」に追加する位置づけ(申請書では将来的フェーズとして提示)

## 5. アプライ先(絞り込み)

### 優先 3 件

| 優先 | 資金源 | 規模 | 理由 | 時期 |
|------|--------|------|------|------|
| ① | **科研費・若手研究**(or 基盤研究C) | 500万/2-3年 | 認知科学×AI×言語の横断性が評価される。**メインターゲット** | 年度内締切(要確認) |
| ② | **学内若手支援/スタートアップ** | 10-100万 | 即効・最短ルート。1万円トークン研究の成果で申請実績 | 随時 |
| ③ | **JST ACT-X**(人と情報のエコシステム等) | 300万/2.5年 | 情報×人文融合領域に適合。中〜高競争 | 年2回公募 |

### 切捨て(現フェーズでは応募しない)

| 資金源 | 理由 |
|--------|------|
| さきがけ / CREST | 競争率極高・規模過大(Phase 4 以降) |
| 財団助成 | 領域マッチの調査に時間がかかる(並行調査のみ) |
| 企業共同研究 | 実演プロトタイプが必要 → Phase 3 以降 |
| クラウドファンディング | 実機・実演がリターンになる → Phase 3 以降 |
| OA ジャーナル APC | 資金獲得後の話 |

2. Guide v2 の手順別寄与(アブレーション) → 生成エンジンの設計原理
3. 評価者分離の評価プロトコル → 方法論的貢献
4. 人間 laughter データは「獲得後のフェーズ」として計画明記
