# RQ01b — PHP をこき下ろす (baseline)

**Seed:** PHPをこき下ろす
**Condition:** baseline (単純プロンプト)

---

新人: 「サイト、作れました」

先輩: 「それPHPで?」

新人: 「はい。動きます」

先輩: 「$_GETを直接使うなって言っただろ」

新人: 「大丈夫です。全部エスケープしてます」

先輩: 「本当か?」

新人: 「エスケープの仕方がわからなかったので、入力を受け付けないようにしました」

先輩: 「それ、サイトの意味がないだろ」

新人: 「でも安全です」

先輩: 「動くのか?」

新人: 「動きます。何も受け付けないので」
