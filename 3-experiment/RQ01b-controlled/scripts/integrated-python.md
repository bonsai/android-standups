# RQ01b — Python をこき下ろす (integrated)

**Seed:** Pythonをこき下ろす
**Condition:** integrated (Comedy Guide v2)
**Structure:** pattern=インデントに人格が宿る世界 / expectation=インデントは作法にすぎない / deviation=インデントが仕様になる / escalation=スペース4つ→レビュー→ロジック削減→if廃止 / reversal=動く理由は「インデントが正しいから」

---

新人: 「スクリプト、書けました」

先輩: 「それPythonで?」

新人: 「はい。インデントはスペース4つで統一しました」

先輩: 「いい心がけだ」

新人: 「スペース4つでないと動かないんです」

先輩: 「……それは、Pythonの仕様だ」

新人: 「いえ。うちの環境の仕様です」

先輩: 「環境?」

新人: 「コードレビューです。インデントがスペース4つでないと、レビューが通りません」

先輩: 「それは正しい運用だな」

新人: 「はい。だから僕は、インデントを合わせるために、中身のロジックを減らしました」

先輩: 「ロジックを?」

新人: 「深いインデントは減らせるので。ifをやめて、全部フラットにしました」

先輩: 「ifをやめたら、条件分岐は?」

新人: 「動くかどうかは、インデントで決まります」

先輩: 「インデントで?」

新人: 「深いものは重要な処理、浅いものは飾りです。レビュアーはそれで読んでます」

先輩: 「……じゃあ、バグがあったら?」

新人: 「インデントを直します」

先輩: 「バグの直し方だろ、それは」

新人: 「直った気がします。深くしたので」

先輩: 「直った気が、か」

新人: 「はい。重要な処理になったので、直った気がします」

先輩: 「……それで、本番は動いてるのか?」

新人: 「動いてます。インデントが正しいので」
