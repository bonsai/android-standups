# RQ01b — Python をこき下ろす (baseline)

**Seed:** Pythonをこき下ろす
**Condition:** baseline (単純プロンプト)

---

新人: 「自動化スクリプト、書けました」

先輩: 「それPythonで?」

新人: 「はい。CSVの処理を自動化しました」

先輩: 「どこまで?」

新人: 「読み込みから書き出しまで、全部です」

先輩: 「エラー処理は?」

新人: 「try exceptで全部握りつぶしてます」

先輩: 「エラーが出たら?」

新人: 「何も起きません」

先輩: 「それでいいのか?」

新人: 「エラーが出てないことになってるので、出てないんです」
