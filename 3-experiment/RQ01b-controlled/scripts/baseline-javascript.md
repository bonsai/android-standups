# RQ01b — JavaScript をこき下ろす (baseline)

**Seed:** JavaScriptをこき下ろす
**Condition:** baseline (単純プロンプト)

---

新人: 「この処理、3行で書けました」

先輩: 「それJavaScriptで?」

新人: 「はい」

先輩: 「型は?」

新人: 「……型は、なんか、動きます」

先輩: 「動くのか?」

新人: 「ブラウザでは動きます」

先輩: 「ブラウザ以外では?」

新人: 「nodeでも動きます」

先輩: 「エラーは?」

新人: 「undefinedが返ってきます」

先輩: 「エラー処理は?」

新人: 「if (value) で握りつぶしてます」

先輩: 「それで大丈夫なのか?」

新人: 「大丈夫です。大丈夫じゃなかったら、NaNが返ってきます」
