# RQ01b — PHP をこき下ろす (integrated)

**Seed:** PHPをこき下ろす
**Condition:** integrated (Comedy Guide v2)
**Structure:** pattern=昔の作法が残る世界 / expectation=現代的で安全なコード / deviation=全部echoの直書き / escalation=echo→SQL→セキュリティ→アクセス / reversal=「動いてます」が唯一の正義

---

新人: 「サイト、できました」

先輩: 「それPHPで?」

新人: 「はい。動きます」

先輩: 「フレームワークは?」

新人: 「ありません」

先輩: 「テンプレートエンジンは?」

新人: 「ありません」

先輩: 「じゃあ何で作ったんだ?」

新人: 「echoです」

先輩: 「echo?」

新人: 「3000回echoしました。HTMLもSQLも、全部echoで」

先輩: 「SQLインジェクションは?」

新人: 「全部エスケープしてます」

先輩: 「どうやって?」

新人: 「受け付けないようにしました」

先輩: 「何を?」

新人: 「全部です。入力があったら、動くページを返すのをやめます」

先輩: 「……じゃあ、そのページ誰が使うんだ?」

新人: 「Googleのクローラーです」

先輩: 「Googleには動くページに見えるのか?」

新人: 「昨日までそうでした」

先輩: 「昨日まで?」

新人: 「今日からは、echoで『サイトは休止中です』と返してます」

先輩: 「……それ、サイトの意味あるのか?」

新人: 「あります。動いてますから」
