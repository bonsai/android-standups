# RQ01b — JavaScript をこき下ろす (integrated)

**Seed:** JavaScriptをこき下ろす
**Condition:** integrated (Comedy Guide v2)
**Structure:** pattern=型なし世界 / expectation=型安全に書かれる / deviation=型は「動けば型」 / escalation=型→本番→原因不明 / reversal=「回ってるように見えてるだけ」

---

新人: 「この処理、1行で書けました」

先輩: 「それJavaScriptで?」

新人: 「はい。1行です」

先輩: 「型は?」

新人: 「型は……動けば型です」

先輩: 「動くの?」

新人: 「今は動いてます」

先輩: 「今は?」

新人: 「本番に入れたらどうなるかは、本番に聞いてください」

先輩: 「聞けるのか?」

新人: 「console.logで聞けば、何か返してくれます」

先輩: 「何が?」

新人: 「undefinedかNaNか、たまに数字です」

先輩: 「それでよくプロダクトが回ってるな」

新人: 「回ってないです。正確には、回ってるように見えてるだけです」

先輩: 「……それ、いつデプロイした?」

新人: 「昨日です」

先輩: 「今日は?」

新人: 「今日は、本番がどこまで動くか教えてくれるのを待ってます」

先輩: 「動くところまでか」

新人: 「はい。動かないところが、明日の仕事です」
