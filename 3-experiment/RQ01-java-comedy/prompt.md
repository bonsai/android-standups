# RQ01 Java Comedy — Prompt

## Seed

```text
JAVAをこき下ろす
```

## Task

Generate a short comedy script from the seed.

## Method

Use Comedy Guide v2:

1. Establish a recognizable pattern.
2. Establish the audience expectation.
3. Introduce a meaningful deviation.
4. Keep the deviation interpretable.
5. Escalate while remaining connected to the premise.
6. Deliver a reversal or punchline.
7. Remove unnecessary explanation.
8. Score and revise the weakest beat.

## Output requirements

- Write a coherent short comedy script.
- Use shared knowledge about Java/software development where useful.
- Do not rely on random insults.
- Make the joke understandable without explaining the joke afterward.
- Perform one critique-and-revision cycle before returning the final script.
